# 🦖 恐龙骑士：远古征途（DINO RIDERS）

一款在浏览器里运行的 3D 恐龙骑乘跑道射击游戏。恐龙沿着远古大道自动向前奔跑，背上的骑手自动开火；你只需要左右走位：撞飞小怪、躲开硬怪和落石、穿过强化门。击败怪物还能让武器一路升到 Lv.10，跑到终点后迎战首领。

游戏有 **20 种恐龙** 和 **10 位骑手** 可选，共 7 个地形关卡，外加一个无尽模式。所有 3D 模型、地形、特效、音效和音乐都是代码实时生成的，项目里没有任何图片或音频素材文件。

## 🌐 在线游玩

**https://zhangxchao.github.io/dino-rider/**

打开网页就能玩，不用安装。推荐用电脑上的 Chrome 或 Edge，手机和平板也能玩。每次推送到 `main` 分支，GitHub Actions 都会自动重新构建并发布（见 `.github/workflows/pages.yml`）。

## 🚀 本地运行

需要 Node.js 18 或更高版本。

```bash
cd dino-rider
npm install          # 已安装过可跳过；国内网络已在 .npmrc 中配置 npmmirror 镜像
npm run dev          # 自动打开 http://localhost:5173
```

macOS 也可以直接双击 `start.command`。

### 打包成单个文件（可离线双击运行）

```bash
npm run build        # 生成 dist/index.html（所有代码内联在这一个文件里）
```

生成的 `dist/index.html` 不需要服务器，直接双击就能用浏览器打开，也可以拷到其他电脑上玩。

### 打包成 Mac 应用

```bash
npm run mac          # 生成 release/恐龙骑士.app
```

- 双击 `恐龙骑士.app` 会用 Chrome 的应用模式打开游戏：独立窗口，没有地址栏和标签页。可以把它拖进「应用程序」文件夹或程序坞，按 `⌃⌘F` 进入全屏。
- 应用里已经内置了游戏，不需要开发服务器，也不需要联网。
- 性能和在 Chrome 里玩完全一样，因为用的是同一个渲染引擎。
- 应用使用独立的浏览器配置，所以存档和浏览器里玩的那份是分开的。
- 电脑上没有 Chrome、Edge、Brave 或 Chromium 时，会改用系统默认浏览器打开。

## 🎮 操作

| 按键 | 作用 |
|---|---|
| `A` `D` / `←` `→` | 左右移动（恐龙会自动向前跑） |
| 按住鼠标左右拖动 | 同样可以左右移动 |
| `空格` / `W` | 跳跃：跳过怪物、落石和地面冲击；落地时震地踩踏周围的怪物 |
| `Q` / `E` / `Shift` | 恐龙专属技能 |
| `R` | 狂热槽满后释放“远古觉醒” |
| `Esc` / `P` | 暂停 |

- 骑手会**自动射击**前方的怪物，恐龙会**自动撕咬**贴身的敌人。
- 镜头固定在恐龙身后，不需要控制视角。容易让人头晕的镜头效果（震动、过弯侧倾、视野拉伸、速度线和速度模糊）默认全部关闭，可以在设置里的「镜头晃动」打开。
- 触屏设备上用左下角的摇杆（或手指左右滑动）移动；技能按钮上直接显示冷却，觉醒按钮里显示狂热进度。手机竖着拿时会提示横过来。
- 第一次玩第 1 关会有新手引导，依次教移动、跳跃、强化门、技能和觉醒；可以在设置里重新播放。

## ✨ 玩法

- **难度**：选关页面顶部可以选 🌱 简单 / ⚔️ 中等 / 🔥 困难（设置里也能改），每一局开始时生效。中等就是原来的数值；简单的怪物少两成、血量 ×0.7、伤害约减半，首领血量和伤害也更低、出招更慢，适合新手和小朋友；困难的怪物多两成、血量 ×1.4、伤害 ×1.5，首领出招更快，通关奖励金币 ×1.5。
- **平衡**：数值用会躲招、会选强化门的机器人实测调过（每组 3～5 局，只跑游戏逻辑）。中等难度下，按关卡进度正常升级，大约四局能赢三局，首领战通常要打 40～70 秒，能打掉你一半以上的血；简单几乎必胜；困难要多刷升级才过得去。10 位骑手的强度也拉到了相近的水平。
- **起伏弯道**：跑道有上坡、下坡和左右弯道。上坡会稍微减速，下坡会加速，过弯时离心力会把恐龙往外侧推，要往弯道内侧打方向。首领战场总是在平地上。
- **跳跃踩踏**：普通跳跃落地会震地，伤害并击飞脚边的怪物。体型越大的恐龙踩踏范围越大，一次踩中 3 只以上会有提示。
- **远古觉醒**：击杀、连击、完美闪避和打首领都会充能狂热槽，满了按 `R` 释放。6 秒内恐龙变大、无敌、撞飞一切，骑手弹幕 +1 道并变成彩虹色，每隔一会儿自动放出冲击波，音乐也会加速。结束时还有一次全屏冲击波。
- **连击档位**：连击到 10 / 25 / 50 / 100 会分别喊出“狂热 / 无双 / 暴走 / 远古之怒”，数字颜色逐级变化。连击越高射速越快（最多 +30%），金币也越多。
- **完美闪避**：跳过怪物，或者在首领砸地的边缘躲开，会触发慢动作“完美闪避”，奖励金币和一大截狂热槽。敌人子弹擦身而过也能充一点。
- **跑图事件**：
  - **跳台**：踩上去会被弹上天，空中前空翻，沿途有一串金币，落地大范围震地。
  - **剧毒小蛛**（丛林）：小蜘蛛不断从树上垂丝落到前方路上，落地后亮出绿圈、蓄力喷出毒雾，伤害和天灾一样重，还会中毒。下落途中就能打掉它。
  - **地形天灾**：一段路上不断出现红圈，丛林落石、沙漠流星、雪原冰锥、沼泽毒泡、火山熔岩弹、暗影紫雷会砸下来，怪物也会被砸到。
  - **宝藏哥布林**：背着金袋往前逃，打它会掉金币，在它跑掉之前打死能爆出一大堆金币和一颗水晶。
  - **精英伏击**：两只精英带着小怪从两侧杀出，击退后前方会出现宝箱。
  - **恐龙蛋**：捡到后孵出一只恐龙宝宝，跟在身边 20 秒帮你撕咬怪物（最多两只）。
  - **新强化门与道具**：🎲 命运骰子门（大多是大奖，偶尔倒霉）、🧲 磁力门和磁铁道具（全屏吸金币）、💣 炸弹道具（捡到就全屏爆炸）。
- **画面冲击**：爆炸会留下焦痕、崩出碎石、点亮周围；疾跑和冲锋有残影（速度线和视野拉伸要在设置里打开「镜头晃动」）；多重击杀和精英击破有慢动作特写。高画质下全部开启，流畅画质只保留轻量效果。
- **冲撞**：血量低的小怪可以直接撞飞。大块头怪物和落石撞上去会受伤，要先打掉或者绕开。宝箱撞碎、打碎都行，里面有金币。
- **武器升级**：击败怪物获得经验，骑手武器会从 Lv.1 升到 Lv.10，依次加伤害、多重弹道、提射速、穿透，满级时子弹还会追踪目标。
- **强化门**：大约每 200 米有一对门，左右各一个，从哪边跑过就拿哪边的强化，比如弹道 +1、射速 +15%、伤害 +20%、穿透、回血、护盾等。
- **首领战**：跑到终点后恐龙停下，首领出现在前方。它出招前地面会出现红色预警，要左右走位躲开，同时持续输出。
- **星级**：通关得 1 星；剩余生命不低于 50% 再得 1 星；消灭 70% 以上的怪物再得 1 星。
- **成长**：金币可以在升级工坊购买永久强化（生命、近战、护甲、移速、骑手武器、技能冷却、拾取范围），对所有恐龙生效。
- **无尽模式**：一开始就能玩（所有关卡也都直接开放，通关后会自动进入下一关）。道路没有尽头，每 1400 米出现一只首领，怪物会越来越强，结束时记录你跑出的距离。

## 🦕 内容一览

- **20 种恐龙**：霸王龙、三角龙、迅猛龙、剑龙、腕龙、棘龙、甲龙、无齿翼龙、副栉龙、异特龙、食肉牛龙、双冠龙、肿头龙、禽龙、南方巨兽龙、镰刀龙、重爪龙、梁龙、戟龙、似鸡龙。每种都有自己的技能，比如咆哮、无敌冲锋、飞扑、旋风、震地冲击波、狂暴、铁甲堡垒、空中轰炸、音波、毒液、音爆、尖刺和疾风冲刺。
- **10 位骑手**：圣光骑士、精灵弓手、烈焰法师、太空宇航员、西部牛仔、暗影忍者、机甲战士、冰雪公主、原始人阿猛、海盗船长。每位骑手的武器和被动加成都不同。
- **3 种语言**：简体中文、English、日本語。第一次打开时按浏览器语言自动选择，之后可以在设置里切换，也可以点标题页右上角的按钮。
- **7 个关卡**：翠绿丛林小径、炽热沙海古道、冰封雪原大道、迷雾沼泽栈道、熔岩火山大道、暗影要塞符文路，以及最终关「螳螂巢穴」：暗红色的地底虫巢，最终 Boss 螳螂王会用十字斩、横扫整条路的镰刃波（要跳过去）和瞬移突袭进攻，三个阶段越打越快。每关的道路都会无限生成，沿途有拱门、火把等地标。

- **每日任务与成就**：每天 3 个任务（击杀、连击、强化门、首领、完美闪避、金币、觉醒等），加上 20 个成就，完成后在标题页「任务与成就」里领取金币。
- **结算**：显示本局得分和总伤害，数字滚动；刷新最短用时会盖「新纪录」印章，第一次通关额外奖励金币，工坊按钮显示能升级几项。

## 🎨 画质

- 高画质：4 倍多重采样抗锯齿、按生态调色、屏幕空间太阳光束、泛光。
- 每关生成一张环境贴图（天空渐变 + 太阳），冰面、水面、盔甲有真实的反射高光；角色带菲涅尔边缘光，在雾里轮廓更清楚。
- 草、花、蕨类和树冠随风摆动；水面有菲涅尔效果。

## ⚡ 性能

- **对象池**：怪物、弹体、恐龙宝宝都回收复用，不再每次出生重建模型和材质；阵型刷怪按预算分帧生成。
- **地形流式生成**：地形高度按行缓存；新的一块地形拆成几步分摊到多帧，逻辑帧最长耗时从约 20～30 ms 降到 7 ms 以内。
- **只上传用到的缓冲**：弹幕、粒子、血条、金币等实例数据只上传实际用到的部分。

- **合并静态零件**：游戏会先把模型动画跑一遍，找出不会动的零件，按"同一父节点 + 同一材质"合并；只差颜色的零件会改用顶点色再合并。
- **刚体蒙皮**：会动的零件（腿、头、尾巴、翅膀…）也合进少数几个蒙皮网格，每个零件的顶点绑定在零件自己身上，动画代码不用改。一只怪物从平均约 32 次绘制降到约 5 次，恐龙加骑手从 92 次（投影再画 92 次）降到 16 次。
- **骨骼图集**：所有怪物和恐龙宝宝共用一张骨骼贴图，每帧只上传一次，不用每只怪物各传一次。
- **按着色器排序**：不透明物体先按用到的着色器分组再绘制，着色器切换从每帧约 180 次降到约 40 次。第 7 关 30 多只怪物同屏时，每帧的 WebGL 调用从约 2300 次降到约 1200 次。
- **批量渲染**：子弹、金币、血条和怪物的圆形投影都是实例化网格，每一类只需要 1～2 次绘制。怪物不再实时投射阴影。
- **开局预热**：开场倒计时期间会预先编译并实际绘制一遍本关会用到的所有着色器，包括强化门的文字贴图和全屏打击感特效，游戏中不会因为第一次出现某种怪、子弹或特效而卡顿。地面红色预警用对象池复用：以前每个预警用完就销毁材质，three.js 会连着色器一起释放，首领每次出招都要重新编译，卡顿 100～240 ms。
- **少画一遍**：半透明的双面特效（冲击波、护盾、拖光、强化门、地面预警）改成单遍绘制；高画质的多重采样只开在后期离屏缓冲上，屏幕缓冲不再重复开。
- **动态分辨率**：看帧时间的中位数，连续两秒低于 50 帧才降一档，降完冷却 6 秒；偶尔一帧卡顿不会触发。提高分辨率要重建后期缓冲，会顿一下，所以只在菜单和暂停时往回调。
- **设置选项**：设置里可以开关"显示帧率"，也可以把画质切到"流畅"（关闭泛光、降低分辨率）。另有全部静音、减少动效（也会跟随系统设置）、手机震动反馈。

## 🗂️ 代码结构

```
src/
  main.js         入口：渲染器、后期处理、场景状态机
  game.js         一局游戏的流程：路线事件、强化门、碰撞、首领战、镜头、结算
  player.js       玩家：自动前进、左右走位、自动射击、武器升级、13 类技能
  enemy.js        怪物 AI、路障（落石/宝箱）与首领招式状态机
  projectiles.js  弹道系统
  effects.js      粒子、冲击波、地面预警、护盾、伤害飘字、镜头震动
  hud.js / ui.js  游戏内 HUD 与各个菜单界面
  track.js        6 种地形的无限跑道（分段流式生成，上下坡起伏）
  bend.js         弯道：在顶点着色器里统一弯曲整个世界
  i18n.js         多语言：界面文案与游戏数据的翻译（locales/ 下是各语言包）
  world.js        菜单背景用的地形场景（地形、植被、天空、天气）
  audio.js        程序化音效与音乐
  models/         恐龙、骑手、怪物、首领的程序化模型
  data.js         全部数值配置
scripts/make-mac-app.sh   打包 Mac 应用
```
