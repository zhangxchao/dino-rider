# 🦖 恐龙骑士：远古征途（DINO RIDERS）

一款在浏览器里运行的 3D 恐龙骑乘跑道射击游戏。恐龙沿着远古大道自动向前奔跑，背上的骑手自动开火；你只需要左右走位：撞飞小怪、躲开硬怪和落石、穿过强化门。击败怪物还能让武器一路升到 Lv.10，跑到终点后迎战首领。

游戏有 **20 种恐龙** 和 **10 位骑手** 可选，共 6 个地形关卡，外加一个无尽模式。所有 3D 模型、地形、特效、音效和音乐都是代码实时生成的，项目里没有任何图片或音频素材文件。

## 🚀 本地运行

需要 Node.js 18 或更高版本。

```bash
cd dino-rider
npm install          # 已安装过可跳过；国内网络已在 .npmrc 中配置 npmmirror 镜像
npm run dev          # 自动打开 http://localhost:5173
```

macOS 也可以直接双击 `start.command`。

### 打包成单个文件（可离线双击运行）

```bash
npm run build        # 生成 dist/index.html（所有代码内联在这一个文件里）
```

生成的 `dist/index.html` 不需要服务器，直接双击就能用浏览器打开，也可以拷到其他电脑上玩。

### 打包成 Mac 应用

```bash
npm run mac          # 生成 release/恐龙骑士.app
```

- 双击 `恐龙骑士.app` 会用 Chrome 的应用模式打开游戏：独立窗口，没有地址栏和标签页。可以把它拖进「应用程序」文件夹或程序坞，按 `⌃⌘F` 进入全屏。
- 应用里已经内置了游戏，不需要开发服务器，也不需要联网。
- 性能和在 Chrome 里玩完全一样，因为用的是同一个渲染引擎。
- 应用使用独立的浏览器配置，所以存档和浏览器里玩的那份是分开的。
- 电脑上没有 Chrome、Edge、Brave 或 Chromium 时，会改用系统默认浏览器打开。

## 🎮 操作

| 按键 | 作用 |
|---|---|
| `A` `D` / `←` `→` | 左右移动（恐龙会自动向前跑） |
| 按住鼠标左右拖动 | 同样可以左右移动 |
| `空格` / `W` | 跳跃：跳过怪物、落石和地面冲击 |
| `Q` / `E` / `Shift` | 恐龙专属技能 |
| `Esc` / `P` | 暂停 |

- 骑手会**自动射击**前方的怪物，恐龙会**自动撕咬**贴身的敌人。
- 镜头固定在恐龙身后，不需要控制视角。镜头震动默认关闭，可以在设置里打开。
- 触屏设备上用手指左右滑动来移动，屏幕上有跳跃和技能按钮。

## ✨ 玩法

- **冲撞**：血量低的小怪可以直接撞飞。大块头怪物和落石撞上去会受伤，要先打掉或者绕开。宝箱撞碎、打碎都行，里面有金币。
- **武器升级**：击败怪物获得经验，骑手武器会从 Lv.1 升到 Lv.10，依次加伤害、多重弹道、提射速、穿透，满级时子弹还会追踪目标。
- **强化门**：大约每 200 米有一对门，左右各一个，从哪边跑过就拿哪边的强化，比如弹道 +1、射速 +25%、伤害 +30%、穿透、回血、护盾等。
- **首领战**：跑到终点后恐龙停下，首领出现在前方。它出招前地面会出现红色预警，要左右走位躲开，同时持续输出。
- **星级**：通关得 1 星；剩余生命不低于 50% 再得 1 星；消灭 70% 以上的怪物再得 1 星。
- **成长**：金币可以在升级工坊购买永久强化（生命、近战、护甲、移速、骑手武器、技能冷却、拾取范围），对所有恐龙生效。
- **无尽模式**：通过第 1 关后解锁。道路没有尽头，每 1400 米出现一只首领，怪物会越来越强，结束时记录你跑出的距离。

## 🦕 内容一览

- **20 种恐龙**：霸王龙、三角龙、迅猛龙、剑龙、腕龙、棘龙、甲龙、无齿翼龙、副栉龙、异特龙、食肉牛龙、双冠龙、肿头龙、禽龙、南方巨兽龙、镰刀龙、重爪龙、梁龙、戟龙、似鸡龙。每种都有自己的技能，比如咆哮、无敌冲锋、飞扑、旋风、震地冲击波、狂暴、铁甲堡垒、空中轰炸、音波、毒液、音爆、尖刺和疾风冲刺。
- **10 位骑手**：圣光骑士、精灵弓手、烈焰法师、太空宇航员、西部牛仔、暗影忍者、机甲战士、冰雪公主、原始人阿猛、海盗船长。每位骑手的武器和被动加成都不同。
- **6 个关卡**：翠绿丛林小径、炽热沙海古道、冰封雪原大道、迷雾沼泽栈道、熔岩火山大道、暗影要塞符文路。每关的道路都会无限生成，沿途有拱门、火把等地标。

## ⚡ 性能

- **合并静态零件**：游戏会先把模型动画跑一遍，找出不会动的零件，按"同一父节点 + 同一材质"合并；只差颜色的零件会改用顶点色再合并。怪物、首领、恐龙的绘制调用因此减少了 50%～80%。
- **批量渲染**：子弹、金币、血条和怪物的圆形投影都是实例化网格，每一类只需要 1～2 次绘制。怪物不再实时投射阴影。
- **开局预热**：开场倒计时期间会预先编译并实际绘制一遍本关会用到的所有着色器，包括强化门的文字贴图，游戏中不会因为第一次出现某种怪或子弹而卡顿。
- **动态分辨率**：帧率低于 50 时自动降低渲染分辨率。提高分辨率要重建后期缓冲，会顿一下，所以只在菜单和暂停时往回调。
- **设置选项**：设置里可以开关"显示帧率"，也可以把画质切到"流畅"（关闭泛光、降低分辨率）。

## 🗂️ 代码结构

```
src/
  main.js         入口：渲染器、后期处理、场景状态机
  game.js         一局游戏的流程：路线事件、强化门、碰撞、首领战、镜头、结算
  player.js       玩家：自动前进、左右走位、自动射击、武器升级、13 类技能
  enemy.js        怪物 AI、路障（落石/宝箱）与首领招式状态机
  projectiles.js  弹道系统
  effects.js      粒子、冲击波、地面预警、护盾、伤害飘字、镜头震动
  hud.js / ui.js  游戏内 HUD 与各个菜单界面
  track.js        6 种地形的无限跑道（分段流式生成）
  world.js        菜单背景用的地形场景（地形、植被、天空、天气）
  audio.js        程序化音效与音乐
  models/         恐龙、骑手、怪物、首领的程序化模型
  data.js         全部数值配置
scripts/make-mac-app.sh   打包 Mac 应用
```
